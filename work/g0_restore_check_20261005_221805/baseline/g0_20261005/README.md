## 2. 物理约定与待解决问题

- 内部长度单位m；数组为[y,x]；x向右、y向上、z朝探测器；逆时针为正，绘图origin='lower'。
- DOE在所有入射波长下使用相同高度。相位为2π[n(λ)−1]Δh/λ，传播复振幅，相机记录模平方；不额外叠加薄透镜相位。
- 非相干光谱按强度叠加。峰值归一化用于展示形状，成像核保留相对输入功率的通光量；有限窗口外的功率不能称为材料损耗。
- 旋转方向与论文观察面/角向定义尚未对齐。G1需要核查，不能靠镜像或旋转已生成图像迎合论文。
- 核心形状半径、峰值阈值面积和绝对R50/R80不同。尺寸近似不变需注明指标及容差，不能仅凭峰值归一化图判断。
- 材料吸收、界面反射、侧壁误差、偏振及真实相机标定尚未模拟或取得。
- PyCharm人工点击与真实GUI尚未人工验证；命令行和mock显示分支的记录不替代人工验证。

公式出处和假设见工程 [公式与参数](../../outputs/jeon2019_optics/docs/equations_and_parameters.md)、[DOE公式与参数](../../outputs/jeon2019_optics/docs/stage02_equations_and_parameters.md)、[02C完成记录](../../outputs/jeon2019_optics/docs/stage02c_completed.md)。原文在本机work/papers/main.pdf与supplement.pdf，PDF不随Git分发。

在PyCharm打开仓库根目录，选解释器后可直接运行main_g0_verify.py。它仅检查内容，不删除、写入、恢复或重算数据。正常退出0，不一致/缺失退出2。

```powershell

```

--code-only通过只表示代码文档匹配，不表示数值证据齐全。manifest.json不包含其自身指纹；Git提交及附注标签绑定清单版本。

**换行符与原始字节快照**：部分历史源码、配置和文档在本地为CRLF，.gitattributes使Git保存为LF；历史来源校验按原始字节哈希，纯Git检出可能因此不相容。code_bytes.zip保存本次代码文档及冻结清单的原始字节，不修改旧代码；newline_inventory.json登记相关文件，verification.json记录ZIP指纹和实际解包核对。恢复时把ZIP解包到一个新的空目录，在该目录运行main_g0_verify.py --code-only，再补齐manifest.json中的本地来源文件。不要覆盖现有工作目录。仅从Git检出运行--code-only，也可能报换行导致的内容变化，这属于预期的字节差异，不能绕过历史来源校验。

Git忽略NPZ数组、论文PDF及多数历史run。本地完整冻结清单也记录未跟踪文件，**标签不等于数组备份**。迁移时保留清单中的本地证据文件及相对目录结构；仅克隆仓库后，默认完整核对会报告缺失。尚未制作并验证独立数组归档或纯克隆恢复流程。不要简单重算一个入口后把新run改名冒充旧来源；重算会产生新来源链，需要按新版本的实际路径和指纹登记。

本次G0使用既有严格来源载入器重验12层来源及12项理想控制，并核对最新02F-3.2的来源证据、源码指纹和完成标记。具体实测版本、文件数量、字节数和检查结果在audit.json登记。

最新基础重建相对cube误差约0.680，仍不能称为高质量论文重建。优化证书针对固定目标最优解，不是真值误差界。现有三波段电子噪声实验的单位和噪声参数也不能直接当作论文25波段RGB训练设置。
