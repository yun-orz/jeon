## 4. 便于理解的物理模型

### 4.1 从几何光学过渡到复振幅

几何光学描述光线的方向；本任务还要描述光波到达不同位置时的相位。复振幅写为 u=A exp(iφ)：A 是振幅，φ 表示振动周期走到哪里。多个路径到达探测器同一点，要先相加复振幅；相位相近会增强，相位相反会抵消。

相机记录的是强度 I=|u|²，不记录复振幅本身。不同波长在通常的非相干曝光下按强度相加，不把不同波长的复振幅直接相加。

DOE 的表面高度改变光程，产生相位延迟。它可以改变传播后各位置的干涉关系；“旋转”应该自然出现在衍射结果中。

### 4.2 固定器件的波长响应

设空气折射率近似为 1，材料折射率为 n(λ)，则正文式(3)写成：

```text
Δn(λ) = n(λ) − 1
φ_h(x′, y′; λ) = 2π Δn(λ) h(x′, y′) / λ
u_1 = u_0 · aperture · exp(i φ_h)
```

复现中生成一次 h，再改变入射 λ 计算 φ_h。给每个入射波长重新生成能聚焦的器件高度，会得到不同器件，不是该论文的编码系统。

空间恒定的 h(0,0) 在理想薄相位屏模型中只增加全局相位，可以用相对高度 Δh 避免大数相位运算。仍须在 metadata 中记录基片厚度，并解释此简化没有模拟基片内传播、多次反射、吸收和界面透射。

### 4.3 Fresnel 传播与采样

正文第 3 页式(4)采用标量 Fresnel 传播：

```text
u_2(x,y) = exp(ikz)/(i λ z) · ∬ u_1(x′,y′)
           · exp[iπ((x−x′)²+(y−y′)²)/(λz)] dx′dy′
k = 2π/λ
```

实现不能只搬运正文式(6)中的“正比于”关系。如果需要能量核验，必须保留积分面积权重、FFT 约定、1/(λz) 等尺度因子。

使用单次 FFT 时，需把频率坐标映射到 x=λz f_x、y=λz f_y。若输入采样为 Δx′，FFT 每维长度为 M，则：

```text
Δx_native = λz / (M Δx′)
Δy_native = λz / (M Δy′)
```

这里的 M 含零填充。不同 λ 的原生输出间距不同，不能把等尺寸数组直接当作同一传感器。零填充加密傅里叶采样，不会补回输入孔径未采到的细节。

后续 PSF 应在统一探测器坐标上计算或映射，并对像素面积积分。可选路线是：验证过尺度的 Fresnel FFT，再建立任意输出坐标的 CZT/Zoom FFT；或者经检验的重采样。后者必须说明插值误差、窗口外能量与像素积分误差。第一阶段先验证原生网格，不强行一次解决整个算法。

Fresnel 模型适用于标量、薄相位屏、近轴传播。仅有 λ≪z 不足以保证准确；还需检查横向偏移相对 z 的大小及被忽略的高阶光程项。大角度或高数值孔径时，后续用角谱法或其他参考模型比较；角谱 FFT 同样需要防止周期回绕和传递函数混叠。

首轮统一采用米制内部单位；配置中可使用 nm、μm、mm，但在入口集中换算。数学坐标 x 向右、y 向上，传播沿 +z。数组行号与图像屏幕上下方向的转换必须明确。

### 4.4 原论文高度图

正文第 4–5 页式(7)–(12)给出构造方法。为避免整数 n 与折射率 n 混淆，用 m 表示相位包裹的整数，用 λ_d 表示设计时的角向波长：

```text
θ_p = θ mod (2π/N)
λ_d(θ) = λ_min + (λ_max − λ_min) N θ_p/(2π)
δ(r) = sqrt(r²+f²) − f
Δh(r,θ) = [m λ_d(θ) − δ(r)] / Δn_design(θ)
```

按正文的负向相对高度约束，选 m=floor(δ/λ_d)，从而：

```text
Δh = −mod(δ, λ_d)/Δn_design
−λ_d/Δn_design ≤ Δh ≤ 0
```

这一包裹表达式是由正文式(9)/(11)推得的实现写法，不是作者公开代码。相位跨越 2π 的边界会产生真实的浮雕跳变，不能用普通图像平滑任意消除。

正文式(11)中折射率的下标与角向设计波长关系没有展开成完整色散实现。采用 Δn_design=n(λ_d)−1 是自然的物理解释，应显式登记；若采用常数折射率，应另作对照，并说明改变的是什么。熔融石英色散模型、系数和有效范围必须来自可靠来源；当前规划不提供猜测系数。

这里 λ_d 只用于制造一张固定高度图。传播时使用真实入射 λ 与 n(λ)，不能在传播循环中用 λ 替换 λ_d 重做器件。

公式正向 θ 的定义与论文图像观察方向需逐一核对。不得在看见旋转方向不符后悄悄镜像 DOE、改传播相位符号或旋转结果图。若需要坐标转换，记录原因和转换前后的角度符号。

### 6.1 阶段 01：传播基线

实现正文式(4)的复振幅传播，先用平面波、圆孔和理想薄透镜进行验证。理想薄透镜的二次相位是传播校验对象，与论文的包裹浮雕 DOE 分开。

至少包括：

- 圆孔加理想薄透镜焦平面 Airy 强度；第一暗环与 1.22λf/D 对照。该表达式为常见近轴圆孔衍射基准，不是 Jeon 独有公式。
- 相同输入下，FFT Fresnel 与小规模直接 Fresnel 积分比较；比较复场时允许去除一个空间恒定的相位因子，不能去掉空间变化相位或任意拟合幅度。
- 输入功率 Σ|u_1|²Δx′Δy′ 与全输出平面离散功率 Σ|u_2|²ΔxΔy 对照。
- 保持实际孔径与观察范围不变，分别改变输入采样间距与 FFT 填充，检查收敛。不能把改变数组尺寸但同时改变器件直径的实验称为采样收敛。
- 将 DOE 平面与探测器平面的坐标数组连同结果一起保存。

建议验收：Airy 第一暗环半径误差≤2%；同网格小规模参考传播的相对 L2 误差≤1e−6；正确尺度下原生 FFT 全平面功率相对误差≤1e−10；加密后的中心区域归一化强度 L1 差≤2%。按算法与精度说明容差，不能对不同输出坐标强行用 1e−6。

原生网格上的 FFT 功率检验主要验证 Parseval 与尺度处理，不足以证明连续空间结果已经收敛。必须同时保留 Airy 尺度、直接积分和采样检查。

### 6.2 阶段 02：器件高度

保持 N=3。保存一张连续相对高度和一个明确约定的量化版本，附参数与数组哈希。先比较径向截线上的包裹残差，再验证三重角周期。常数折射率与色散折射率作为明确分支。

建议在避开跳变边界的样点上检查 `(δ+Δn_design Δh)/λ_d` 距离最近整数的误差≤1e−9。这验证高度公式的代数正确性，不替代 PSF 仿真。

未找到量化确切规则时，写明采用的取整方式、零位和饱和处理。未经说明不得把连续高度按自身 min/max 拉伸到 16 级。

### 6.3 阶段 03：图 3 趋势

每个波长：加载同一高度 → 用该 λ 的材料响应生成复透过率 → 衍射传播 → 强度 → 统一探测器坐标及像素积分。

输出至少含两行九列：固定 Fresnel 对照、固定三翼 DOE。使用相同物理视场和坐标轴；灰度是量化分析依据，伪彩色只用于表达波长。峰值归一化图与保留积分尺度的 PSF 分别保存。

先解释“形状相近且方向变化、尺寸较稳定”的趋势，不要求九个 PSF 是完美刚性旋转。图 3 的作者渲染存在未知的色彩、曝光和缩放设置，不能把渲染差异当作完整物理误差。

### 6.4 阶段 04：正式旋转、尺寸、旁瓣与收敛

三翼图样具有 120° 周期，普通二阶协方差主轴可能不稳定，不能只靠 PCA 定义旋转角。计划结合角向相关配准与三阶角谐波：

```text
C3 = ∫∫ I(r,θ) w(r) exp(i3θ) r dr dθ
θ3 = arg(C3)/3   （模 120°）
```

w(r)、径向区间、中心估计和展开规则预先固定。三阶谐波幅度太小时标记角度不可信；相邻波长相关估角作为交叉检查。旋转配准仅用于测量角度，不能用于生成 PSF。

检查建议：

- 记录数学角度、屏幕观察角度和展开后的连续角度；确认与论文顺时针描述之间的坐标对应关系。
- 尺寸同时用质心、r50、r80 与约定区域的二阶矩表示；报告视场截断对统计量的影响。
- 三翼 PSF 没有唯一“中心主瓣”；旁瓣指标须先定义目标支撑区域，报告区域外能量、峰值和径向能量分布。阈值随意挑选的区域不宜用来证明高效率。
- 输入采样至少三个等级，填充/计算窗口与输出积分网格分别检验。固定物理孔径和材料，不让器件随网格变化。
- 收敛建议：最终两级 r50/r80 差≤2%、角度差≤1°、固定观察区归一化强度 L1 差≤2%；逐波长记录，不仅检查 550 nm。
- 不预设“尺寸完全不变”作为成功指标。报告九波长尺寸变化幅度和相对 Fresnel 对照的改善，判断是否支持论文的定性表述。

### 6.5 阶段 05–06：编码与基础重建

以正文式(13)–(15)为前向模型。若 I_b 表示每单位波长的能量型图像，离散化为：

```text
J_c = Σ_b Ω_c(λ_b) [I_b * K_b] Δλ_b
K_b = η_b p_b
```

p_b 是单位和形状核，η_b 是所选探测窗口/透过率模型对应的效率因子。如果 I_b 已是带宽积分值，则不能再次乘 Δλ_b。若 Ω 使用量子效率且输入以能量计，转换电子数时还需 λ/(hc) 等光子转换，不能重复计入已包含的响应。

未有可信 Canon 曲线时，可以用 Ω=1 的理想单色传感器验证模型，标为替代探测器；合成 RGB 曲线必须明确“示例响应”，不得当成 Canon 标定值。论文原系统以 RGB 响应参与重建，理想单色验证不等于完整原相机复现。

先用小型可控合成场景，检查单波段、两波段与平坦场景。图像卷积采用明确的边界条件，防止 FFT 循环卷积把边缘能量绕回。

基础重建可选非负约束与空间/光谱正则化。先检验前向和伴随的内积一致性，再检查残差与已知立方体误差。单次快照欠定，低残差不能证明光谱恢复准确；增加光谱平滑先验后改善也不能声称算法恢复了任意窄谱线。首次不训练原论文网络。
