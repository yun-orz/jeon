# G5固定场景复测：扩充模型与原模型同输入比较

这是“Jeon光学编码复现＋基础重建验证”的固定场景诊断，不是完整原论文复现。img5没有用于梯度更新或epoch选择，但之前已经看过其成绩，因此本步**不是新的盲测或无偏的最终泛化证明**。本轮0次训练，不按本轮成绩更换模型、尺度、区域或超参数。

## PyCharm运行与配置

解释器选Python3.10.4，依赖沿用requirements_g3.txt。直接右键运行main_g5_retest.py，无参数CPU运行，完全使用本地保存的模型和测量，不下载数据或依赖Harness/聊天、Notebook、Docker、GPU。

config_g5_retest.json集中指定source_test/test_audit（原img5测试run及审核）、source_expanded/expanded_audit（扩充训练run及审核）、cpu_threads（默认4）、runtime保存/显示开关、plots.dpi。来源文件及其代码清单必须与已审核SHA一致；指标尺度和区域从原测试记录读取，不提供另选高分区域或逐图尺度的开关。所有相对路径按入口所在工程解析，不依赖启动目录。

命令行：`python -B main_g5_retest.py`；`--no-save`仅推理和计算、不写结果；`--show-plots`请求手动弹窗查看（本轮GUI未人工验证，后端探测状态写入JSON）。重复保存使用新的results/g5_retest/run_*，不覆盖旧结果。

## 固定的物理与数据协议

输入复用已审核原img5的4个128×128上下文及同一RGB测量，只评价中央32×32×25。原训练尺度0.019641629936370968、相对灵敏度校正、λ/540相对光子表示、420:10:660nm波段、原G1高度/25核及G2合成RGB响应全部保持一致。没有为每波段重新设计DOE，没有旋转图片，没有噪声/CFA/gamma注入，预测和目标不裁剪。

光谱PSNR固定L=1、合并MSE；逐波段11×11高斯valid SSIM；SAM以有效像元的平均rad报告，零谱另外计数。详细定义见G5_README.md。没有绝对光子标定，当前谱表示与论文反射率/辐射谱未完全对齐。

原预测直接复用旧测试数组并重算指标，新预测由扩充训练最佳epoch8 checkpoint冻结推理。原模型SAM重算值.49373230074290103与旧JSON .493732300742901有约5.55e−17的舍入差：浮点汇总核对用1e−12绝对容差，实际最大差另记；整数、布尔、null、字段必须严格一致。原数组、模型及单位没有改变，首轮严格相等误报记录保留。

## 测量一致性是什么

对预测的完整128×128×25上下文用同一Φ重新编码成128×128×3 RGB，**先卷积再裁中央区域**。ROI外的光会被PSF扩散进ROI，先裁cube再卷积将漏掉这部分贡献。

保存中心RGB MSE、相对L2=||Φ(pred)−y||/||y||及完整上下文MSE；残差及分母统一float64计算，零测量时相对误差无定义，写null并计数。测量单位沿用合成线性相对响应，非真实相机绝对电子数。完整上下文边缘仍受零延拓/有限域影响，不能与中心残差混为一个指标。

较低的RGB残差说明输出更能解释编码测量，但RGB只有3通道、目标有25波段，存在非唯一性，所以**数据拟合好不保证光谱正确**；必须同时看GT的PSNR/SSIM/SAM、光谱形状与空间细节。

四块来自一幅场景，不是四幅独立测试图，也不是整幅图像性能。原验证2块的27.75dB不能代替本场景24.72dB。图像仍可能过度平滑，指标改善不等于完整细节恢复。原测量窗口、有限域边界和论文光学尺寸问题仍需进一步验证。

不是论文十幅KAIST测试协议；真实RGB响应、定量光学对齐、原网络细节和完整训练仍有缺口，paper_alignment_passed=false。当前不启动新DOE或双孔径G6；新的盲测需在模型和协议冻结后用此前未查看的场景另行完成。
