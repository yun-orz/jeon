## 物理含义与论文依据

正文PDF第5页式(13)–(15)将各波长强度图与对应PSF卷积，再乘相机光谱响应并对波长积分。连续形式为Jc=∫Ωc(λ)(Iλ*pλ)dλ，离散矩阵为J=ΦI。正文第7页说明原型为Canon EOS 5D Mark III，采用无自适应白平衡的去马赛克RGB，并直接标定整体测量矩阵Φ=ΩP。

本程序采用已审核原G1的固定N=3单孔径连续高度核库，未悄悄切换为CW诊断变体。核库来源results/g1/run_20261005_231424；器件指纹8527724f6aeffc0314d09313d89fdca0c2c864827e6a47308480968bcabc1350。来源对照上轮保存的完整SHA清单，并核对其代码指纹、波长、物理坐标和高度指纹；不是仅信任一个passed字段。

每个核K_b的元素是像元积分功率/孔径输入功率，和为有限PSF窗口捕获比例η_b≈0.865–0.942。成像保留这个效率；不除以核和。传播过程见G1_README.md及G1_ALIGNMENT_README.md，G2读取核不重新设计DOE，也不旋转/镜像图片造PSF。

不同波长是非相干强度相加：

```
y[h,w,c] = Σ_b R[c,b] · C_b(x[:,:,b])[h,w] · s
s = 1                         输入为 photons_per_bin
s = bin_width_nm (=10)        输入为 photons_per_nm
```

输入每个空间像元为进入该物体投影点成像模型的期望光子数，已按曝光/空间像元积分，不是W/m²或光子面密度，因此不再乘像元面积。25个波长代表420:10:660nm波段；假设各带内响应与PSF由中心值代表，未仿真带内积分或作者端点带宽处理。输入每波段已积分则不能再乘10nm；每nm谱密度才乘带宽。若改用能量谱，必须另外定义λ/(hc)、曝光及增益转换，本阶段明确拒绝“power”等未实现单位。

R是电子/光子的合成QE，默认RGB中心610/540/460nm、标准差45/35/30nm、峰值0.6，表达式R_c(λ)=peak_c·exp[-0.5((λ−center_c)/sigma_c)²]。只在25个中心波长评价，未进行曲线外推。这些参数是人为预声明测试设置，不来自Canon或作者，不能用于声称相机标定精度。

输出为三个理想线性平面的期望电子数：未加读出/光子噪声、CFA采样、去马赛克、白平衡、gamma、饱和或增益。此三平面接口不能直接等同原型相机原始Bayer读出。空间模型暂采用同一6.22μm投影像元网格和移不变近似，离轴PSF、物距及视场变化未验证。

## 卷积边界与伴随

采用零延拓、线性full卷积及中心same裁剪，不是周期卷积；97×97核中心为[48,48]（从0开始）。只支持奇数核尺寸，图像允许奇偶尺寸。Φᵀ先将RGB按响应转置混合，再与中心反转的PSF作同域卷积；这个边界下通过欧氏内积检查。带宽因子在Φ及Φᵀ中都出现。

Φᵀ是数据项梯度计算所需的伴随，不是Φ的逆，也不是已重建的HSI。算子允许带符号向量用于优化与内积检验，物理场景输入则拒绝负光子数。
