## A. 物理模型假设

### A1. 标量、近轴、薄相位屏
- **出处**：论文第 3 页式(4) 明确使用 Fresnel 衍射积分，并给出条件 λ≪z。
- **采用值**：标量衍射；Fresnel（二次相位）近似；DOE 视为无限薄相位屏。
- **影响**：忽略偏振、忽略相位屏厚度内的传播与多次反射、忽略大角度项。
- **替代值**：Rayleigh–Sommerfeld 第一类积分或**精确角谱**
  （`fresnel_angular_spectrum`，`H = exp(ikz√(1−λ²f²))`，与频域 Fresnel 近似
  `H = exp(ikz)exp(−iπλz f²)` 是**两个不同的传播子**，不得混称）。
- **当前结论**：**λ≪z 只是必要条件，已另行量化高阶项**，用**精确**路径差

  ```text
  ΔL = √(z²+ρ²) − z − ρ²/(2z) = −ρ⁴/[2z·(√(z²+ρ²)+z)²]
  相位误差 = |(2π/λ)·ΔL|
  ```

  `ρ` 取**实际输入支撑与输出窗口的角点距离**（方形窗口计入角点）。
  旧版公式含多余的 `(L²/8z²)(L²/z²)·2` 高阶因子，把 ρ=1.25 mm 处的
  0.0279 rad 误报为 4.1e−11 rad（2026-10-01 更正）。
  本项目容忍度取 0.1 rad（**非论文数值**）。A 组三个算例实测
  9.8e−2 / 1.6e−1 / 1.6e−1 rad，在论文尺度 D=1 mm 处**已略超**该容忍度，
  如实记录为已知的近轴残差。

### A2. 理想薄透镜的二次相位仅用于验证
- **出处**：任务书第 5 节 A 项要求；论文的 DOE 是包裹浮雕相位（式(7)–(12)）。
- **采用值**：`u₁ = aperture · exp[−iπ(x′²+y′²)/(λf)]`，传播 z = f。
- **影响**：这是**传播程序的校验对象**，与论文的 DOE 无关；不得据此宣称复现了图 3。
- **当前结论**：A 组三个算例（含论文尺度 D=1 mm）的第一暗环相对误差
  1.8e−3 / 1.9e−3 / 2.1e−3，中心截线 L1 3.9e−4 / 2.1e−4 / 4.8e−5。

### A3. 理想透镜焦平面 = 孔径的 Fourier 强度（2026-10-01 更正）
- **出处**：任务书用 1.22λf/D 作为对照。旧版本假设"该式只在远场
  `N_F = D²/(4λf) ≪ 1` 成立"，**这是错的**。
- **采用值（更正后）**：在 `z = f` 的焦平面上，透镜相位
  `exp(−iπr′²/(λf))` 与传播展开式的**输入二次相位** `exp(+iπr′²/(λf))`
  **相消**，于是焦平面场就是孔径的 Fourier 变换，圆孔给出 Airy 图样。
  该结论**与 `N_F` 无关**，不需要 `N_F ≪ 1`。
- **正确数值**（λ=550 nm）：0.1 mm/50 mm → N_F = 0.090909；
  0.2 mm/25 mm → N_F = 0.727273；1 mm/50 mm → N_F = 9.090909。
  旧版报告里的 2.3、4.5 是错的。
- **影响**：**论文尺度 D=1 mm、f=50 mm 现在是正式算例**，不再是"只做解析核对"。
  但要注意：`N_F` 大时焦平面上**相邻暗环的间距**仍由 1.22λf/D 给出，
  而近轴条件与数值采样条件必须逐项检查（A1、B1）。
- **替代值**：若需要非焦平面或非理想透镜，应改用 Fresnel 积分的数值参考。
- **当前结论**：`Fresnel 数`只作报告；Airy 校验由解析式与数值截线直接比较。

### A4. 输入窗口必须容纳真实场
- **出处**：本项目实测得到；任务书未规定。
- **采用值**：A/C/D 组的输入窗口半宽取孔径半径的 2.5–6 倍
  （本次运行：0.1 mm 孔径用 ±300 μm，0.2 mm 用 ±300 μm，1 mm 用 ±1200 μm）。
- **影响**：窗口过紧会**截掉真实存在的外围衍射光**，在能量核验里表现为"丢失"。
- **当前结论**：能量**主判据**改为**原生 FFT 全输出 Parseval**（不裁剪任何窗口，
  实测相对误差 ≤2.2e−14）；"有限窗口对解析包围能量"只作**补充**检查，
  用**绝对差**（两者定义不同：解析式是无限平面占比，离散场在窗内尚未积完）。

## B. 数值与实现假设

### B1. 离散求和的适用判据（本项目实测确定，非论文数值）
- **采用值**：**完整被积函数**三部分相位的步进之和 ≤ **0.5 rad**：

  ```text
  输入二次相位 : π(2·x′_max·Δx′ + Δx′²)/(λz)
  交叉项       : 2π(|x|_max·Δx′ + |y|_max·Δy′)/(λz)   ← 按实际输出窗口边缘估计
  输出二次相位 : 对求和变量没有步进
  ```

  半宽按 `(n//2)·d` 计算，**不**额外乘 0.5（旧版多乘了 0.5，2026-10-01 更正）。
- **依据**：旧版只用输入二次相位单项，不足以约束全部评价点；
  修正后同时给出三项与保守和，并明确标注"这不是通用精度保证"。
- **影响**：旧版据此断言"单次 FFT 形式在本项目参数下不可用"，
  **该结论已撤回**——真正原因是旧实现漏乘面积权重 `Δx′Δy′` 且频率数组未中心化。
- **替代值**：需要固定小视场细采样时，可以用 `fresnel_kernel_separable`
  （完整核的可分离求值，`O(N_out·(Nx′+Ny′))`），或增大 FFT 长度 M。
- **当前结论**：所有正式运行的判据值与结论都写入 `run.log`、`metrics/*.csv`
  与 `acceptance_check.json`。

### B2. 面积权重与尺度因子
- **出处**：式(4) 的 `dx′dy′` 与 `1/(iλz)`。
- **采用值**：**所有**路径的复场里都同时含 `Δx′Δy′` 与 `1/(iλz)`。
  原生 FFT 全输出 Parseval 因此就是 `P_out = P_in`（同一场在两个平面上的功率相等），
  **不需要**任何额外因子。
  > 旧版此处给出的 `P_out = P_in/(λz)²·(ΔxΔy)/(Δx′Δy′)` **是错的**
  > （2026-10-01 更正）：它是把"漏掉的面积权重"错误地写成了理论期望。
- **影响**：漏掉 `Δx′Δy′` 会让 FFT 结果相对完整核求和偏差 `1/(Δx′Δy′)`：
  Δx′=40 μm → 6.25e8，Δx′=10 μm → 1e10（旧版的实测值）。修正后 ≤2.6e−13。
- **当前结论**：尺度因子已有测试与验收断言（Parseval ≤1e−10，实测 ≤2.2e−14）。

### B3. 只允许去掉一个全局相位
- **采用值**：比较复场时可用闭式最优全局相位 `e^{iθ} = ⟨b,a⟩/|⟨b,a⟩|`
  （`optics.metrics.remove_global_phase`），**不排除任何空间变化相位，不做幅度拟合**。
- **接口语义（2026-10-01 明确）**：
  - `include_global_phase` **只**控制 `exp(ikz)` 一个因子，从不涉及 `1/(iλz)`；
    默认 True，与直接积分一致。测试断言两条路径的比值恒为 `exp(ikz)`。
  - `omit_output_quadratic_phase=True` 返回的是**另一种场表示**
    （把输出二次相位解析地除掉），**不是同一个物理复场**；元数据里明确标注。
    已知限制：采样角点上的相位幅角可达上百 π，用浮点公式独立重构该相位会失去
    有效位，因此它只应用于输出网格很小的诊断场合。测试固定了这两条语义。
- **当前结论**：测试中同时报告"含全局相位"与"去全局相位"两个数值。

### B4. 零填充区振幅为零
- **采用值**：零填充区振幅为 0；采样判据按**实际有值的输入范围**计算，
  但交叉项按**实际输出窗口**估计。
- **影响**：把填充后半宽代入判据会严重低估相位步进（本阶段实测过这一误导）。
- **当前结论**：`sampling_diagnostics` 分别给出三项步进与保守和，并标注
  "这不是通用精度保证"。

### B5. 二维数组与图像方向
- **采用值**：`a[j, i]` ↔ `(x_i, y_j)`，**索引增加时 x、y 都增加**；
  显示用 `origin="lower"`，extent 取**像素边界**（`extent_pixel_um`）。
  > 旧版此处写"行指标增加时 y 减小"，与实现相反（2026-10-01 更正）。
  > 实现本身（`coords = (arange(n) − n//2) * d`）一直是递增的，未改动。
- **影响**：轴翻转会同时污染 PSF 旋转方向的判断，因此**必须在阶段 01 固定**，
  后续阶段不得重新定义。测试显式断言行/列方向。
