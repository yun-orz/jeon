# 02D-2：基础非负岭重建执行与限制

2026-10-02。本批实现、运行及程序审核已完成；实际合成场景的优化收敛仍未完成。名称严格为“Jeon光学编码复现＋基础重建验证”，不是原论文网络复现。单完整N=3孔径、三诊断波长；无双孔径、N=1、GPU、噪声或实际相机响应。

## 模型、单位及来源

沿用02D-1前向模型与伴随：y=CΣ_b R_b(X_b*K_b)，R_b=1，K_b=像元积分功率/孔径输入功率，保留η，不重复乘像元面积。场景为理想像平面点源的三单色积分相对功率；有限PSF窗口、有限场景支持、移位不变假设、物理坐标及旋转方向限制全部保留。

源场景run：`results/stage02d1/run_20261002_203904`，源光学run：`results/stage02c/run_20261002_172338`。只读重验成像源码、6份场景身份、固定核/高度指纹/波长/坐标/响应、各波段full编码与full/crop测量；再重验三张DOE及九组q8光学场和Pin/η，源目录SHA前后不变。物理公式/参数出处仍为正文PDF第5–7页及既有材料假设，见02C记录；本批不改DOE或传播公式。

## 求解器与先验

求解min_{X≥0} F(X)=0.5||AX−y||²+α||X||²/2；g=A*(AX−y)+αX，X_next=max(0,X−g/L)。正则项惩罚较大幅值，是最基础的数学先验，没有原论文网络或已知真值位置/光谱先验。α>0使该岭目标严格凸，但其唯一正则解不必等于真实cube。

幂迭代估计L_data≈||A||²，固定种子2019，至多100轮、相对Rayleigh商变化阈值1e−8；它不是严格上界。实际α=1e−4×L_data。每步回溯检查平滑目标二次上界，初始L=1.05(L_data+α)，回溯倍数2、至多50次；回溯耗尽明确失败，不静默返回。

零初始化。停止要求归一化投影梯度映射||L[X−max(0,X−g/L)]||/||A*y||≤1e−5，以及目标相对变化≤1e−7。零算子/零测量单独定义，防止除零。目标小、残差小或达到500轮均不单独表示收敛。默认max_iterations=500，所有场景采用同一规则。

真实cube仅用于验证来源测量一致性及求解后评价，求解函数只接收A、y、配置和谱估计，没有真实cube参数。没有每场景用真值选择α。两器件与full/crop算子谱不同，有效α略不同；不能声称这些对照完全只改变一个因素。
