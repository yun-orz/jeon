# Jeon2019 阶段 02A：物理与数值假设清单

## 1. 核心光学与材料假设

1. **薄相位元件（Thin Phase Screen）与无损模型**：
   - 假设光波穿过 DOE 时仅产生纯空间相位延迟 $\phi_h(x', y') = \frac{2\pi}{\lambda}(n(\lambda)-1)h(x', y')$，器件内部横向光场演化被忽略。
   - 忽略二氧化硅介质与空气界面的菲涅尔反射损失（未引入 Fresnel 反射系数）、材料体吸收与多次内部反射。
   - **影响声明**：此模型计算得到的全平面能量守恒与窗口透射率代表理想无损上界，不能直接等同于实际加工器件的衍射效率或真实相机的信噪比。

2. **材料色散模型**：
   - 采用 Malitson (1965) 熔融石英在 20°C 下的标准 Sellmeier 三项模型（DOI: 10.1364/JOSA.55.001205）。
   - 环境空气折射率取常数 $n_{\text{air}} = 1.0$。
   - **文献与代码事实**：Jeon 2019 正文第 4 页式 (11) 下标使用 $\Delta\eta_\lambda$，但未在论文正文中给出折射率的具体测量数值或公式实现代码。本项目引入 Malitson 模型作为物理自洽的标准模型，**不能称为作者官方代码实测核准的设置**。

3. **照明光源模型**：
   - 采用来自无限远正入射的理想单色相干平面波，振幅恒为 1.0，初相恒为 0。
   - 阶段 02A 未引入有限物距点源或非相干扩展宽带光源。

4. **高度连续性与加工模型**：
   - 阶段 02A 采用完全连续的浮雕微结构高度 $\Delta h(r, \theta)$，不对高度做阶梯离散。
   - 论文第 6–7 页提及的 16 级光刻台阶与 100nm 高度量化留待阶段 02C 实现。

## 2. 坐标与数值计算假设

1. **Fresnel 传播近似**：
   - 标量近轴 Fresnel 衍射积分基于近轴假设（小角度传播）。
   - 在当前孔径 $D=1\,\text{mm}$、焦距 $f=50\,\text{mm}$ 下，三阶展开理论公式保守估计的高阶相位误差约为 $0.0144\,\text{rad}$（此数值为解析公式保守估计，并非实验或全波物理测量值）。$\lambda \ll z$ 是必要条件但不能单独无条件保证标量近轴 Fresnel 严格成立。
   - 采用直接可分离矩阵求积，输出直接落在预设物理网格上，不依赖单次 FFT 的波长依赖输出网格插值。

2. **输入网格采样**：
   - 输入网格取 $[-550, 550]\,\mu\text{m}$，样点间距 $\Delta x' = 1\,\mu\text{m}$（共 $1101 \times 1101$ 点）。
   - 保证了半径 $500\,\mu\text{m}$ 的圆孔有完整边界覆盖（采样面积相对理论圆面积误差 $\approx 0.006\%$）。

3. **输出探测网格**：
   - 共同物理探测窗口取 $[-150, 150]\,\mu\text{m}$，样点间距 $\Delta x = 1\,\mu\text{m}$（共 $301 \times 301$ 点）。
   - 该网格仅用于衍射场点求积采样，**不是实际相机传感器的 $6.22\,\mu\text{m}$ 像元积分**（像元面积积分将在阶段 02C 实现）。

## 3. 未验证范围与边界声明

1. **未证明 PSF 尺寸恒定**：实测三波长绝对包围能量半径 $R_{50}$（以输入功率为分母）存在明显差异（420nm 约 $82.4\,\mu\text{m}$，540nm 约 $48.9\,\mu\text{m}$，660nm 约 $90.6\,\mu\text{m}$），在当前离散模型下尚未证明光斑物理尺寸恒定；峰值归一化图像仅用于观察三翼形状，不能代替绝对通量与尺寸分布的定量判定。
2. **未验证图 3 完整九波长旋转曲线**：阶段 02A 仅计算 420nm、540nm、660nm 三个离散波长，作为原理与代码链条打通的证据；顺时针角度随波长定量曲线留待 02B。
3. **未验证 DOE 采样收敛性**：高度台阶跳变处的材料相位采样是否充分尚未开展多级加密对比（留待 02B）。
4. **未包含场景图像与高光谱重建**：未运行卷积、深度学习去卷积或任何非相干图像复原算法。
5. **未涉及单螺旋与并排双孔径**：本阶段严格按照论文原作者推荐的 $N=3$ 单孔径三翼结构执行。
