# M2：正式光学与RGB算子

目标：冻结Jeon与Fresnel共用物理、响应、探测器和单位协议。依赖M0，不依赖GPU。只写新代码/新数据/新M2结果；旧G1–G5源码、核和器件指纹保持不变。

输入：M0参数/来源/保护清单；G1 CW `results/g1_alignment/run_20261005_234023`；G1窗口、LightPipes及5120审核。实际源路径与SHA从M0历史索引取得。固定高度SHA `3469c7a4717a765d31e0433d9180c015520e00b99d08a0c656e791ac2b917f51`。不把三个控制波长检查冒称全25波段或无限域收敛。

实施：

1. 新入口实现 `optics`。Jeon固定N3/CW/连续高度、D1mm、f=z50mm、420:10:660nm。复用已审核材料公式，冻结公式、所有参数和证据；不逐波长重设计高度。
2. 对全部25波段执行1µm/0.5µm输入及q4/q8像元求积。公共97×97、6.22µm物理坐标。L1≤.005、L2≤.01、eta绝对差≤.001、角度差≤.5deg、半径≤1pixel，按原G1定义逐项审核；不满足先诊断，不放宽。
3. Fresnel固定550nm设计波长，与Jeon同材料、孔径、传播、采样和探测器。保留有限窗口效率，不归一化为每波段质量1。
4. 若作者响应未取得，下载 `sources.json` RAWtoACES同型号JSON；冻结原始文件、版本/提交或访问内容SHA及许可证。按实际380–780nm/5nm表取420–660nm；处理共同相对响应尺度，不独立放大各通道/波段，不称绝对QE或作者标定。
5. 明确相对能量/谱密度/带能量的离散含义，10nm权重只计一次，禁用旧λ/540光子换算。M3拟合之前共同测量增益保持pending；可冻结物理包，再用带父指纹的新最终包绑定训练集增益，不能悄悄改包。
6. 半尺寸核使用物理像元面积重叠映射到49×49、12.44µm。保持原97像元有限窗口质量及几何原点，保存面积映射与外侧空面积。不能直接插值后逐波段乘不同增益。独立点质量/对称核/质心案例核对。
7. 新适配层验证NumPy/Torch前向、伴随内积和自动微分；FP64相对误差≤1e-10。保存原生/半尺寸核、响应、谱权重、单位、指纹和报告，满足 `contracts.json`。

实际验证：`main.py optics --config <有效配置>`；独立采样/质量/质心/卷积核对；`main.py check`。实施新增的optics命令和参数后，把实际可执行完整命令写报告。不得以图3无标尺外观反复调D/f/材料。

成功：两算子25波段采样门槛、质量映射、数值检查通过；所有参数和单位可追溯，训练增益的未拟合状态明确，供M3冻结最终训练包。旧模型仅历史诊断，后续正式模型从头训练。
