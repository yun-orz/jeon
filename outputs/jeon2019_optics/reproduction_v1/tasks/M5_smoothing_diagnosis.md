# M5：平滑瓶颈定位与训练预演

目标：在完整训练前验证可学习性，获得能区分成因的诊断。依赖通过的M4及最终算子/数据协议。只写新代码和新M5结果；测试封存，旧流程仅作为诊断来源。

输入：M4恢复训练器及验收报告、最终算子/数据/训练配置指纹、预先固定的真实训练与验证样本，及只读旧流程诊断来源；不输入封存测试成绩。

实施：

1. 实现 `smoke`。固定低维谱合成场景、无噪单patch过拟合，最多1024次更新；记录初始/最终及曲线，L1下降至少90%，所有阶段梯度有限且能参与更新。欠定3×25不能要求恢复任意25维谱。
2. 在固定真实训练小集合、固定预算上预演，预先选训练外的结构丰富/低纹理/暗区/不同谱形验证样本，不按结果挑“最好看的”样例。
3. 保存每个HQS阶段数据项、先验项、eps/rho/tau、阈值占比和预测变化，定位先验压平、失效阶段或尺度失衡。谱核每频率3×25矩阵报告最多3个非零奇异值及波段列相关性，注明先验承担的不可辨识部分。
4. 同小集合和更新预算比较旧流程诊断、正式256监督、关软阈值诊断。旧流程算子/单位/中心32监督差异必须单列，不能将其当成正式公平对照；诊断变体不自动替代正式配置，不扩大架构搜索。
5. 仅验证集检查halo64/96/128、池化相位及接缝。最终固定128；中央有效区域96→128相对变化>1%不通过。报告比较区域、误差分母与有效mask，不仅用三个近乎平坦ROI推广整图。
6. 高频误差结合GT质量/校正mask解释，区分细节和源噪点。冻结M4首轮配置，失败先修复恢复与数值问题再复验，不跳到M6。

实际验证：`main.py smoke --config <预演配置>`；固定样本验证；阶段记录重载；halo比较；`main.py check`。所有随机种子、样例、诊断变体、实际更新数写入报告，测试不参与。

成功：合成≥90%下降、梯度/数值检查、halo门槛通过；形成有证据瓶颈报告及正式训练冻结配置。输出所有预演run、诊断图和最终配置SHA，供M6。

预算≤8h/空间/学习失败：完整保留曲线、模型和恢复链；未到1024或未达门槛如实标未通过，不能把执行过smoke写成passed。本阶段成功后停止，首轮正式方法仍M4配置。
