# M7：最终测试与论文差异报告

目标：执行封存10幅KAIST的一次最终评价，建立公平Fresnel对照。依赖M6两模型完整规定预算、最佳权重及评价协议冻结。只写新代码/新M7结果；不再训练或按测试修改超参数。

输入：M3封存测试清单、M6两最佳checkpoint、最终算子包和共同增益、M0指标来源及协议指纹。先核对模型/数据/配置不可变，明确记录此次测试开封时间及原因。十幅场景而非patch数。

实施：

1. 实现 `evaluate` 和完整 `report`。整场景GT先编码，之后分块推理，保留ROI外光贡献；零延拓的外场边界明确。固定halo128，网络池化相位按8倍网格对齐，输出覆盖/有效mask/边界和接缝诊断。
2. 对同一目标，无噪及sigma=.005两条件；预定种子、同共同增益、配对噪声和评价范围。Jeon与Fresnel各用自己正式训练的模型，不能拿一模型换核评价作正式对照。
3. 指标用固定范围1 PSNR、11×11 sigma1.5 Gaussian valid SSIM、逐像元SAM。测量和预测不因测试而裁剪/重归一化。SAM输出rad与deg和无定义像元数；mask、边界、SSIM窗口有效性、标准差口径均声明。
4. 逐图/逐波段计算，报告10图均值及标准差；另报合并MSE/PSNR，不能混用旧patch合并PSNR。保存全部场景缩略图、预定ROI对照、谱曲线、误差图、重编码残差、时间/峰值显存和逐图原始数值。
5. 独立实现核对代表性前向、PSNR/SSIM/SAM，不调用同一指标函数作为独立实现；报告差值、阈值和真实失败。
6. 中文最终报告分别列论文确认一致项、实施假设、未取得作者资料和真实性能差异。35.88/.93/.12仅文献参照，SAM未知单位/名单/实现差异明确保留，不能因程序通过或数字改善标paper_alignment_passed=true。

实际验证：`main.py evaluate --config <冻结评价配置>`；独立代表性前向与指标审核；`main.py report`；`main.py check`。报告列两模型SHA、每场景文件SHA、种子和有效范围，读回保存数值核对。

成功：十场景两方法两条件输出齐全，独立核对通过，条件与训练预算一致，测试没有用于选epoch或调参。输出新M7最终报告、完整成绩和图件、开封记录及整体验收。

预算≤8h/空间/指标失败：保留逐场景完成进度，恢复只补同冻结条件的未完成场景，不重新抽样噪声或改指标；无全量完成标记。成绩低则如实交付剩余瓶颈证据；后续调参必须把十图标已查看，称固定测试复测。任务完成后停止，不启动新DOE或真实实验。
