# 固定DOE的5120周期域稳定性补核

本阶段延续Jeon光学编码复现诊断，保持同一CW高度及三控制波长，未设计新DOE、未训练/替换G2–G5核。5120结果采用SciPy低内存等价周期Fresnel算子，**没有直接调用LightPipes的5120 Forvard**；先在4096域与上一阶段实际LightPipes场逐项核对。

## 本地运行

PyCharm打开main_g1_padding.py直接运行，config_g1_padding.json集中设置来源/审核、5120域、分块64行、三波长及比较阈值。路径按入口位置解析；CPU无Notebook、Docker、GPU、Harness或聊天依赖。环境沿用CPython3.10.4、NumPy2.2.6、SciPy1.15.3、Matplotlib3.10.9。本入口不需要导入LightPipes，但核对其已安装源码及旧结果SHA，须保留独立库目录。

默认保存results/g1_padding/run_*，不覆盖旧结果；--no-save只读复算，--show-plots请求弹窗。所有图和关键数值自动保存。人工PyCharm点击/GUI未验证。

## 等价实现与物理条件

当前可用内存实测约4.54GiB，LightPipes大域实现包含多张全域实/复数组。本批用SciPy单工作线程FFT、分块生成H，只保留必要复场缓冲，依次执行4096及5120，释放临时场。该实现仍需数个大复数组的内存，不能称任意电脑都能运行。

H(fx,fy)=exp(ikz)exp[−iπλz(fx²+fy²)]，k=2π/λ；相同周期域、输入采样1µm和z50mm，不是精确矢量或非近轴传播。频率fftfreq(N,dx)，数组零填充中心与原1101场一致。分块只减少传递函数临时内存，不截断频率或改孔径。每波长复用同一固定DOE生成的已保存u1，不插值高度或旋转图片。

LightPipes Forvard使用略不同π常数，复场按最佳单位全局相位另核对，不调整幅度；原生强度和相机核均保持实际通光比例。4096场相对库场须小于预设1e−7。主比较使用同一609原生坐标、6.22µm像元、q8中点及线性强度插值，仍包含上一阶段已标注的经验插值差，尚非严格误差上界。

记录4096实际LightPipes核到5120等价核的相对L1/L2变化，以及5120对固定点积分参考核误差，沿用1%工程门槛。门槛通过只代表本批三控制波长和有限相邻域；不能推广到25波段、整图或无限域，也不证明论文图3尺寸/作者版本对齐。paper_alignment_passed=false。
