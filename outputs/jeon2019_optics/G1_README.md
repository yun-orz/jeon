## 2. 物理概念、公式和出处

几何光学描述光线方向；这里要描述每个孔径位置的光的**相位**。光在探测器某一点的复振幅，是整个孔径贡献的带相位求和；各处同相时增强，异相时抵消。最后相机记录复振幅模平方，而不是相位或复数本身。

同一DOE高度Δh改变光程。材料折射率随波长变化，因此固定高度的相位响应也变：

```text
u1(x',y';λ) = M(x',y') exp{i 2π[n(λ)−1]Δh(x',y')/λ}
u2(x,y;λ) = exp(ikz)/(iλz) ∬u1(x',y';λ)
             exp{iπ[(x−x')²+(y−y')²]/(λz)} dx'dy'
Iraw(x,y;λ) = |u2(x,y;λ)|²
Pjk(λ) ≈ Σab Iraw(xj,a,yk,b;λ)(p/q)²
Kjk(λ) = Pjk(λ)/Pin(λ)
```

M是完整圆孔掩膜，k=2π/λ，p是像元间距，q是每轴像元内求积密度。传播的面积权重dx'dy'及1/(iλz)均保留，未额外加入理想薄透镜。输入场幅度1是相对辐射基准，不声称真实光源功率。

## 3. 坐标、采样与固定器件

全部长度单位m；数组[y,x]，x右、y上、z朝探测器，逆时针为正，显示origin='lower'。主输入1101×1101、1μm，范围±550μm；完整圆孔直径1mm。

25个波长为420:10:660nm。像元中心始终为(j−48)×6.22μm，中心范围±298.56μm，像元边界范围±301.67μm。q8的776×776求积节点间距0.7775μm。直接传播到相同物理节点，不使用波长相关FFT坐标作为相机坐标，不插值生成器件PSF。

主高度只生成一次，每个波段计算后重验内容指纹。二倍输入加密是在2201×2201、0.5μm网格上采样相同解析设计，窗口仍±550μm；细网格也只生成一次并跨25波段固定。细网格指纹与主网格不同是正常的空间离散变化，不能据此称为每波长重新设计器件。

本批只计算continuous器件。02C的nearest_depth/floor_depth制造对照仍保留，G1未扩展其25波段核，也没有单螺旋或双孔径。

## 4. 归一化与输出含义

psf_bank.npz中kernels形状为[25,97,97]，轴顺序[波长,y,x]，每项为像元功率/入射孔径功率，**每个核的和不强制等于1**，而是有限窗口捕获比例。成像时不能再乘一次像元面积；G2需要另行定义光谱密度、积分权重及传感器响应。

psf25_shapes.png各幅除以自己的峰值，只方便比较形状；它不能用于通光效率比较。figure3_nine_absolute.png使用共同的未峰值归一化核尺度。窗口外功率未被相机局部窗口捕获，不等于材料吸收。

R50/R80表示相对于**输入孔径功率**的绝对包围能量半径，按像元中心离散归属，不插值；它不同于50%峰值阈值面积的等效半径。外围功率定义为当前方窗内r>150μm的功率/Pin，含螺旋翼及弱光，不称为严格旁瓣率；未规定主瓣区域时，不能直接套用单峰Airy旁瓣定义。

本批项目筛查容差沿用02C：L1≤0.5%、L2≤1%、捕获比例差≤0.001、角差≤0.5°、半径差≤一像元。细输入和q8是较细数值参考，不是解析真值或严格误差界。
