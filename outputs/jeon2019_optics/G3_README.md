## 为什么需要先验网络

25个波段经过各自PSF模糊，再混合成3个RGB通道。Φ能算“一个光谱场景会产生什么测量”，但通常不能唯一倒推场景。Φᵀ把RGB误差传播回各个波段，是伴随而不是逆矩阵；之前G2保存的回投影也不能自动叫光谱重建。

HQS将观测一致性和图像先验拆开处理。数据项要求解码结果通过Φ后接近RGB观测；先验网络提供空间与光谱结构约束。U-net的多个尺度让网络看到较宽空间范围，以应对较大PSF；软阈值处理内部学习特征，不是裁掉低强度光子或相机噪声阈值。

## 原文与代码对应

来源为项目根work/papers/main.pdf，PDF第5页图4/5、第6页式(16)–(21)与5.2/5.3节、第7页实现细节。论文使用TensorFlow；本实施版使用本地可用的PyTorch。API核对依据：

- https://docs.pytorch.org/docs/2.14/generated/torch.fft.rfft2.html
- https://docs.pytorch.org/docs/2.14/generated/torch.nn.ConvTranspose2d.html

| 原文结构 | 实现 |
| --- | --- |
| 式(16)：数据项＋未知先验R(I) | 用监督L1损失测试展开网络可学习性，不声称显式求得未知R |
| 式(18)：观测误差＋ρ·约束误差＋R(V) | 数据更新与先验分离；ρ对应原文ς |
| 式(21)：I_next=I−ε[Φᵀ(ΦI−J)+ρ(I−V)] | HQSStage逐项实现，并独立重算其等价展开式 |
| I0=ΦᵀJ | 初始化为G2匹配边界的伴随回投影，无额外增益补偿 |
| 图4先验作用于当前I，得到V | 每阶段先计算V_l=S_l(I_l)，再更新I_l；下一阶段对更新结果使用下一独立先验 |
| 图5多尺度、池化、上卷积、跳连、软阈值 | SpectralPrior实现，各分辨率两次3×3卷积，max-pool，转置卷积上采样，拼接跳连，最终特征软阈值与3×3输出卷积 |
| 5.3节每阶段独立学习参数 | 每阶段独立U-net、ε、ρ及软阈值，完全不共享权重 |
| 原文L1训练损失 | 本轮仅对一个合成patch执行两次Adam更新，学习率1e−4，不替代原文训练 |

式(21)按原文不额外乘梯度系数2；平方范数的这个系数可吸收到ε。网络输出没有再强制非负或强制能量归一化，避免悄悄修改更新式；随机网络可有负值，未将其解释为可直接测量的物理光谱。

## 明确的实施假设与差异

- 原文只以L符号给出展开次数，本次未查到明确数值；默认L=3仅为工程验证选择。
- 原文5.2节写Γ大于64，Section 6实际实现写Γ=64；默认按实现段使用64。
- “四层”实现为四个分辨率、三次池化，通道[64,128,256,512]；原文未公开完整通道表，这是实施假设。
- 未公开激活、padding、bias、初始化、软阈值的完整参数化。本版卷积使用ReLU、零padding及bias，最后解码特征保留符号，再作sign(x)·max(abs(x)−τ,0)，最后输出25波段；τ是每阶段单个学习标量。
- ε、ρ、τ采用softplus参数化保证正值；默认初值0.05、0.1、0.01是预声明测试设置，不是论文标定值。正参数化本身不保证全网络收敛。
- 网络特征对右/下补零到池化可整除尺寸，再裁回原大小；光学卷积始终使用原图像域。没有把光学边界改为周期边界。
- 本轮没有原文的完整数据、238幅训练图、增强、30,000个256×256patch、原文噪声与训练日程，也没有原文半尺寸PSF/图像的训练协议。

因此只能称为论文公式与架构框架的实施版，不能声称精确复刻作者未知细节。原G1的手性及尺寸限制保持原记录，本轮没有将CW诊断高度写成官方DOE或改用于网络。

## Φ、Φᵀ与归一化

TorchRGB读取G2同一25×97×97固定DOE核与3×25合成响应，核保持有限窗口通光效率。rfft2前零填充至(H+Kh−1,W+Kw−1)，得到线性full卷积，再中心same裁剪。伴随翻转奇数核，与G2零延拓边界一致，不是循环卷积。张量内部[N,波段,H,W]，保存数组仍采用[H,W,波段]；RGB对应[N,3,H,W]。

观测和光谱同时除以固定scale=1000，保持线性Φ不变；没有分别归一化通道或每张图峰值。网络计算用float32，独立光学参考及梯度检查用float64。

从96×96立方体中心取32×32合成patch作为梯度验算目标。必须对裁剪后的立方体重新用零延拓Φ生成对应32×32测量，不能直接裁大图RGB，因为大图RGB含patch外光的卷积贡献。本程序已实际重新编码，并保存smoke_target/smoke_rgb作为证据。
