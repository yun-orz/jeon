## 3. 适合从几何光学过渡的物理解释

几何光学把光看成沿光线传播；本程序还保存波的相位。数组中的每个复数同时表示该位置的振幅和相位。
透镜给入射场乘一个位置相关的复指数，然后每个孔径位置的波以传播核贡献到探测面，各贡献先按复数相加，再取模平方。相位不同会产生相长或相消，因此强度出现中心光斑和旁瓣。

正文第3页式(4)的离散形式是：

```text
u_out(x,y) = exp(ikz)/(iλz) × Σ u_in(x',y')
             × exp{iπ[(x−x')²+(y−y')²]/(λz)} × Δx'Δy'
I_out = |u_out|²；k=2π/λ
```

内部长度均为m，数学坐标x向右、y向上；`u[j,i]`对应`(x[i],y[j])`，显示使用`origin='lower'`。
面积权重和`1/(λz)`决定绝对幅度，不能因为图形看起来相似就删掉。
这是标量、近轴Fresnel模型；与它的解析参考一致，不能证明任意大角度下也符合真实光学。代码保留了精确光程误差和采样提示，提示与收敛结果分别解释。

薄透镜的二次相位为`exp[-iπr'²/(λf)]`。在z=f时，它恰好抵消传播展开式的输入二次相位，焦平面强度等于孔径傅里叶变换的模平方。
圆孔因此得到Airy图案，不要求Fresnel数很小。论文硬件尺度D=1mm、f50mm、550nm对应第一暗环约33.540922μm；本阶段用理想二次薄透镜校验这一尺度。

### 为什么现在的能量计算可以更小

```text
P_in = Σ|u_in|²Δx'Δy'
P_disk(R) = Σ_(x²+y²≤R²)|u_out|²Δx_outΔy_out
E_numeric(R) = P_disk(R)/P_in
E_analytic(R) = 1−J0(v)²−J1(v)²；v=πDR/(λf)
```

在理想无损模型中，全平面输出功率等于输入功率，因此只需要计算圆盘内的分子，分母无需靠巨幅输出场近似。
默认直接核只计算能覆盖该圆盘的小窗口；原生FFT全输出Parseval用另一组算例单独检查，不能相互替代。
严格全零的输入区域可省略求和，但非零孔径、相位和原物理坐标都没有改变。

图形归一化只用于观察形状；采样收敛主要比较未归一化强度。有限方窗内条件比例`P_disk/P_square`另有标签，不用它冒充绝对通量。
径向曲线采用样点面积求积，小半径处会有离散圆盘边界造成的台阶；能量主验收针对预设R，另做20/40级加密。
超出方窗内切圆的半径无法得到完整圆盘积分，因此不与解析完整圆盘曲线比较。

### 两种采样检查解决不同问题

- 输入网格加密：验证对器件/孔径的积分是否足够精细。当前固定器件，用2、1、0.5μm输入间距，在同一探测器坐标比较。
- FFT填充：固定同一张离散输入，改变M1024/M2048，让输出间距改变；强度映射到公共物理网格，再与直接核参考比较。
- FFT与同一离散直接核相等：验证算法实现与尺度，不能单独证明上述两类连续收敛。

单次FFT原生输出间距为`Δx_out=λz/(MxΔx')`，y方向独立计算。以后不同波长必须映射到同一个探测器物理坐标，再进行光谱成像。
本阶段没有将FFT数组索引当作固定探测器坐标，也没有通过旋转已有图像来模拟衍射。

常用参数集中在`config.json`：

| 参数 | 含义 |
| --- | --- |
| `runtime.show_plots` | 请求图窗；CLI `--show-plots`可以开启 |
| `runtime.save_results` | 是否保存；CLI `--no-save`可强制关闭 |
| `studies.airy.cases` | D、f、输入/输出间距及能量评价 |
| `energy_evaluation.method`、`energy_levels[].method` | 默认`direct_window`；`fft`为可选较重的交叉验证 |
| `samples_per_dark_ring` | 能量网格每第一暗环半径的样点数；越大越细，成本也上升 |
| `R_over_r1` | 评价圆盘半径除以理论第一暗环半径 |
| `fft_size` | 仅在能量方法为`fft`时生效；D组填充研究仍必须实际使用FFT尺寸 |
| `studies.sampling.input_levels` | 输入器件采样间距；物理孔径和窗口保持固定 |
| `studies.sampling.padding_levels` | 同一输入下的输出采样/FFT填充尺寸 |
| `acceptance.*` | 各指标预先约定的阈值；不是论文实验误差 |

`enabled=false`会跳过对应计算；默认必需组被禁用则验收失败。主动选成功子集时状态为partial；已执行项失败仍返回非零。
