## 3. 必须修正的问题

### S1 [P1] “去掉输出二次相位”分支多乘了一个负二次相位

位置：`optics/propagation.py:446–450`；对应弱测试 `tests/test_propagation.py:442–467`。

令 `q=π(x²+y²)/(λz)`，完整场为 `u_full=C·F·exp(iq)`。因此省略表示应当为 `C·F`。
当前代码返回 `C·F·exp(-iq)`，实际与完整场相差 `exp(-2iq)`。

独立结果：补回一次 `exp(iq)` 后相对 L2 **1.4618**；补回两次后仅 **1.07e-15**。
同一算例相位最大约432 rad，正确相位的除去再乘回误差 **1.11e-16**。
因此“相位上百π导致不能逐点检验”的解释不能成立；相位欠采样影响空间插值，不妨碍已知坐标上计算解析指数。

此问题不改变本次单平面 PSF 强度，但会破坏复场相位，影响后续传播与相位核对。必须修复分支，并增加能检验准确相位关系的测试。

### S2 [P1] 真正的输入/填充收敛仍未完成

位置：`main.py:628–718`；`tests/test_propagation.py:101–126, 367–396`。

- D 组参数 `D` 没有参与输入场构造，配置中的物理孔径不生效。
- D 组各级只比较“FFT vs 同一离散输入的直接核”。两者共同欠采样时也可以精确相等。
- `worst_pair_L1` 实际保存的是复场相对 L2；不是不同采样等级的强度 L1。
- `test_two_padding_factors` 调用的辅助函数完全没有使用 `pad`，两次都是相同的直接积分。
- 没有在公共物理网格上比较不同填充倍率的输出。

独立比较固定当前 D 组输入函数和输出窗口 `[-200,200] μm`，以 N=2048 的完整位移核计算为数值参考：

| 输入 N | 输入间距 μm | 未归一化强度相对 L1 |
| ---: | ---: | ---: |
| 32 | 125 | 142.50 |
| 64 | 62.5 | 34.91 |
| 128 | 31.25 | 7.310 |
| 512 | 7.8125 | 0.01070 |
| 1024 | 3.90625 | 0.002642 |

N=2048 是数值参考，不声称无限精度解析解；N=1024 与其已明显接近。当前 N32/N64/N128 的严重误差与 D 图中的重复光斑一致，不能标作采样稳定。新任务规定分别验收离散恒等、输入采样收敛和输出采样/填充收敛。

### S3 [P1] 包围能量用错分母，图注与计算不一致

位置：`main.py:349–355, 543–589`。

解析 Airy 包围能量是 `P_disk(R)/P_total`。当前代码计算 `P_disk(R)/P_square_window`，再直接与解析式比较。C 图还写“未重新归一化”，实际除以了有限方窗内的强度和。

对同一组已保存的未归一化数组，独立重算：

- 当前分母口径：0.997251411。
- 正确口径 `P_disk/P_in`：0.967471360。
- 解析式：0.967472476。
- 正确口径绝对差：**1.12e-6**，不是当前报告约0.02978的“必然系统差”。

A 组二维窗口只到方形半宽 `2.5r1`，最大半径 `3.5355r1`，却计算 `r≤5r1` 的比例。因此所有像素被选中，离散比例恒为1，是空检查。应增加足够大的能量评价窗口或使用明确较小的圆盘，并以输入功率作为分母。

### S4 [P1] 总验收会漏掉真实失败

位置：`main.py:975–976, 1013–1037`。

1. B 组结果存入 `results['direct']`，验收却读 `results['direct_vs_fft']`。只运行 B 组时，其结果会被标为 `not_run`。
2. Airy 只读取 `cases[0]`，第二组和论文尺度第三组不会影响总体判定。
3. 采样项套用另一个指标，见 S2。

独立负面测试：

| 故意引入的失败 | 应有行为 | 当前实际行为 |
| --- | --- | --- |
| B 组阈值设为0；实测误差>0 | B项 fail，非零退出码 | B项 not_run，退出0 |
| Airy第一项0.001，后两项0.5/0.7 | 后两项 fail，非零退出码 | 只取第一项 pass，退出0 |

此外，已请求执行却缺测的必需检查不能算通过；主动选择子集且已执行项均通过时，可以报告 `partial` 并退出0。README 应区分这两种情况。

### S5 [P2] 精确角谱忽略全局相位开关

位置：`optics/propagation.py:520–523, 560–565`。

`include_global_phase=False` 传入精确角谱后没有生效。对单位均匀平面波，不填充时关闭全局相位应返回单位场；当前相对误差0.563465，两个开关的输出完全相同。

### S6 [P2] 配置开关未接入运行逻辑

位置：`main.py:97–98, 932–935`；`config.json:6–12`；`README.md:48–55`。

`runtime.show_plots` 和 `runtime.save_results` 都没有参与对应决定。README 所述“改配置就可以弹窗”与代码不一致。配置需要在后端选择前读取，统一计算最终 show/save 状态，命令行参数再明确覆盖。此次不把未实际验证的 GUI 路径写成已通过。

### S7 [P2] 采样诊断仍混用输入与输出间距

位置：`optics/propagation.py:168–218`。

输出二次相位的步进使用了输入 `dx`，不是输出网格实际间距；输入二次相位只算 x 方向，可能漏掉更粗的 y 方向。应分别报告 x/y 输入积分与输出场表示的采样提示，未知输出间距时标记未评估，不能给出伪数值。提示不应代替收敛验证。

### S8 [P2] 测试辅助函数的倾斜高斯解析包络缺少平移

位置：`tests/test_propagation.py:70–89`。非零倾斜输入的包络应平移到 `(z·θx,z·θy)`，现有解析辅助函数仍把包络固定在原点。它目前只在零倾斜解析对照中被调用，所以不改变已通过的正入射结果；倾斜测试只核对了峰值，没有检验该辅助函数。

独立算例 θx=1mrad、z50mm：现有表达式复场误差0.48395；补上包络平移后为5.88e-16。应修复参考函数并增加非零倾斜完整复场对照，避免后续把错误参考当作传播故障。
