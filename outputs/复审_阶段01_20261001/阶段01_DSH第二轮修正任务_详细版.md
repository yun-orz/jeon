## 2. 必须保持的物理模型与约定

论文来源：`work/papers/main.pdf` 第3页式(4)，正文传播复振幅。补充材料位于 `work/papers/supplement.pdf`。
本阶段 Airy、连续高斯与 Parseval 是数值校验参考，不要把它们写成论文图3的实验结果。

全部内部长度单位为 m；配置可用 nm、μm、mm，但只在入口转换一次。
数组 `u[j,i]` 对应 `(x[i],y[j])`，行列递增分别表示 y/x 递增；显示 `origin='lower'`。
传播的是复场，相机强度为 `I=abs(u)**2`；FFT 使用负指数。

完整位移核：

```text
u_out(x,y) = exp(ikz)/(iλz) · Σ_j Σ_i u_in(x'_i,y'_j)
             · exp{iπ[(x−x'_i)²+(y−y'_j)²]/(λz)} · Δx'Δy'
k = 2π/λ
```

FFT 展开式：

```text
V = 中心对齐零填充后的 [u_in · exp(iπ(x'²+y'²)/(λz))]
F = fftshift(fft2(ifftshift(V)))
C = Δx'Δy' · exp(ikz)/(iλz)
q_out = π(x²+y²)/(λz)
u_full = C·F·exp(iq_out)
x = λz·fftshift(fftfreq(Mx,Δx'))
y = λz·fftshift(fftfreq(My,Δy'))
Δx_out = λz/(MxΔx')；Δy_out = λz/(MyΔy')
```

直接核不能再预乘输入二次相位。默认 FFT 已修好，不要破坏面积权重、中心对齐和矩形/奇数输入支持。
零填充改变输出间距，不增加输入器件的实际采样精度。两个方法对同一欠采样输入精确相等，也不能证明连续场正确。

## 4. S5：统一两种频域传播的全局相位开关

这部分改动小，可在输入采样研究之前完成。

### 4.1 正确传递函数

```text
Fresnel 近似：
 H_true  = exp(ikz)·exp[-iπλz(fx²+fy²)]
 H_false = exp[-iπλz(fx²+fy²)]

精确角谱（当前标量平面波模型）：
 s = sqrt(1−λ²(fx²+fy²))，复平方根取使 z>0 倏逝分量衰减的支路
 H_true  = exp(ikz·s)
 H_false = exp(ikz·s)·exp(-ikz)
```

`include_global_phase` 只控制 exp(ikz)。不得去掉 Fresnel 积分的 `1/(iλz)` 或改变强度。
两种传播名称、网格与适用近似继续区分。角谱方法中的周期边界、零填充和输出裁剪需要说明。

### 4.2 验收

- 两种方法分别验证 `u_true ≈ exp(ikz)·u_false`，相对 L2≤1e-10。
- 使用不填充、均匀单位平面波：关闭开关后场等于1；开启后等于 exp(ikz)。
- 非对称输入也执行该开关测试，不能只比较方法名称。
- 保存开关组合数值；涉及倏逝分量时不得强制宣称全输出严格无损，Fresnel Parseval 的主检查仍单独执行。

## 5. S3：修复绝对包围能量

### 5.1 统一同一个分母

```text
P_in       = Σ |u_in|² Δx'Δy'
P_disk(R)  = Σ_(x²+y²≤R²) |u_out|² Δx_outΔy_out
E_numeric  = P_disk(R)/P_in

E_analytic = 1−J0(v)²−J1(v)²
```

## 6. S2：实施真正的两类收敛研究

必须把“离散算法恒等”“输入积分收敛”“输出采样/填充收敛”作为不同指标。旧粗采样例可保留为欠采样演示，不得继续列为物理收敛通过。

### 6.1 D1：固定器件和公共输出坐标，改变输入采样

推荐一个 CPU 成本可控的明确算例：

| 参数 | 建议值 | 作用 |
| --- | --- | --- |
| λ | 550nm | 单色检查 |
| 理想圆孔直径 D | 0.1mm | 必须真正进入孔径函数 |
| f=z | 50mm | 二次薄透镜焦平面 |
| 输入半宽 W | 200μm | 所有等级固定 |
| 输入间距 | 2、1、0.5μm | 三个精度等级 |
| 输入坐标 | `(arange(n)−n//2)·Δx'` | 可用奇数201/401/801点覆盖同一边界 |
| 公共输出窗口 | x/y均覆盖±2r1 | 同一物理范围，r1由Bessel零点计算 |
| 公共输出间距 | 不大于2μm | 所有等级使用同一组坐标 |

每一级都根据同一个连续圆孔及理想透镜公式取样，不把粗网格图像放大作为精细器件。
使用完整位移核或正确分离核在公共坐标求值，可绕开为全二维FFT获取极细输出所需的巨大内存。
同时保存输入孔径、输入复场、输入功率、输出复场和原始强度。

在同一物理网格上计算：

```text
raw_intensity_L1(a,b) = Σ |Ia−Ib| ΔA / [Σ Ib ΔA]
shape_L1(a,b)        = Σ |Ia/Pa−Ib/Pb| ΔA
Pa、Pb为同一观察窗内对应强度积分，仅用于明确标注的形状比较
field_relL2(a,b)     = sqrt(Σ |ua−ub|² ΔA / Σ |ub|² ΔA)
```

- 主输入收敛建议：最后两级原始强度相对 L1≤0.02，记录0→1及1→2两组比较。
- 保存每一级与解析 Airy 的中心截线误差、第一暗环和输入孔径面积误差。
- 不用 `abs(error_a−error_b)` 替代两张强度的实际差；两个不同错误可能恰好相等。
- 粗级不满足阈值时真实标出；以预先约定的最终两级判定最终精度，不把失败悄悄删掉。
- 保留论文尺度 D=1mm 的 A 组检查，不能用小孔径取代原有论文尺度验证。

### 10.1 S8：修复倾斜高斯解析参考函数

`tests/test_propagation.py::free_space_gaussian` 的倾斜选项当前缺少包络横移。
对输入 `exp[-(x²+y²)/w0²]·exp[ik(θx x+θy y)]`，同一近轴 Fresnel 模型的完整解析复场是：

```text
q = 1+i zλ/(πw0²)
u(x,y,z) = exp(ikz)/q
           · exp{-[(x−zθx)²+(y−zθy)²]/(w0²q)}
           · exp{ik[θx x+θy y−z(θx²+θy²)/2]}
```

这里θ表示近轴线性相位系数，不混用tanθ、sinθ的精确几何表达式。
局部修正辅助函数及其注释，新增θx=1mrad的直接积分对解析完整复场测试，相对L2≤1e-6。
θ=0时应退回现有正确高斯解。可追加x/y双方向倾斜，防止轴交换。
独立审核发现现有表达式误差约0.484，补上平移后约5.88e-16；不要硬编码这些输出。
