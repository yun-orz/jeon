## C. 物理公式和坐标约定

### C1. 坐标、单位和数组

### C2. 高度设计：正文式(7)–(12)

不要把式(9)中的整数n和材料折射率n混用；代码用 `wrap_order` 和 `refractive_index`。

```text
r = sqrt(x'^2+y'^2)
delta(r) = sqrt(r^2+f^2)-f
         = r^2/(sqrt(r^2+f^2)+f)   # 数值稳定形式
theta_period = mod(atan2(y',x'), 2*pi/N)
lambda_design(theta) = lambda_min
    + (lambda_max-lambda_min)*N*theta_period/(2*pi)
wrap_order = floor(delta/lambda_design)
delta_h = (wrap_order*lambda_design-delta)/(n_design-1)
        = -remainder(delta,lambda_design)/(n_design-1)
```

`lambda_design`是每个角方向的设计标签，并不是当前照明波长。
在原点指定θ=0，`lambda_design=lambda_min`，`delta_h=0`。
在孔径内逐点满足 `-lambda_design/(n_design-1) <= delta_h <= 0`，允许接近绕回边界的浮点容差；不得对高度跳变做平滑。
孔径外设高度0并另存mask，不让孔径外进入统计；圆孔不能裁成半圆。

本批实现假设：`n_design=n_fused_silica(lambda_design)`。正文式(11)下标仍写Δηλ，而未完整披露色散计算细节；这个代入是物理一致的实施选择，**不能说是作者代码已核实的处理**。
在中文假设文档明确它及影响；若发现原文更明确的解释，以可核对原文证据修订并说明。

固定器件保存相对高度 `delta_h` 即可。为展示制造高度可加统一常数 `H_offset`：`h_positive=delta_h+H_offset`，只改变每波长的全局相位，不改变PSF。
本批不需要把0.5mm基底离散到高度图；均匀基底的相位可作为全局因子省略并声明。
不计界面反射、吸收、多次反射及加工误差，采用无损薄相位屏；这里的理想通量不能称为真实器件效率。

### C3. 材料色散：来源、单位与假设

默认使用Malitson熔融石英Sellmeier模型。它是材料模型假设，不是Jeon作者批次实测折射率。
来源：[Malitson 1965，Optica原文摘要及色散公式](https://opg.optica.org/josa/abstract.cfm?URI=josa-55-10-1205)，DOI `10.1364/JOSA.55.001205`。
原文模型对应20°C、0.21–3.71μm范围；本项目只使用0.42–0.66μm。公式中的L单位为μm：

```text
n(L)^2-1 = 0.6961663*L^2/(L^2-0.0684043^2)
         + 0.4079426*L^2/(L^2-0.1162414^2)
         + 0.8974794*L^2/(L^2-9.896161^2)
n = positive_sqrt(1 + above)
L = wavelength_m*1e6
```

空气近似 `n_air=1`，不额外推断实验温度、湿度或厂家牌号。
保存材料名称、系数、单位、来源URL、有效范围、假设温度以及所用n值。
建议独立点值验算：550nm时n约1.45991（检查绝对误差≤2e-5；报告所用独立参考计算），可见光区n为有限数且随波长增大下降。
输入≤0、NaN或超出声明范围时明确报错，不默默把nm当m，也不外推。

### C4. 固定高度的波长响应：正文式(2)、(3)

```text
phase_h(lambda_in) = 2*pi/lambda_in
    * (n_fused_silica(lambda_in)-n_air) * delta_h
u1(lambda_in) = circular_aperture * exp(1j*phase_h)
```

采用轴上、单位振幅、零常相位平面波，有限物距不在02A中实现。
只在初始化时生成一次高度。循环里禁止调用DOE设计函数，也不能把 `lambda_in` 代入角向设计图重新生成器件。
三波长共享同一高度数组、mask、输入网格及器件SHA256。
DOE已经包含聚焦设计，**不能再乘 `ideal_thin_lens_phase`**；它仅用于独立阶段01式控制，不属于DOE前向场。

### C5. 传播与强度：正文式(4)

```text
u2(x,y) = exp(i*k*z)/(i*lambda*z)
    * sum[u1(x',y')
      * exp(i*pi*((x-x')^2+(y-y')^2)/(lambda*z))]
    * dx_in*dy_in
I_raw(x,y) = abs(u2)^2
```

复用 `fresnel_kernel_separable(field_in, grid_in, wavelength, distance, x_out, y_out, include_global_phase=True)`。
它使用两次一维核矩阵乘法，保留完整位移核，直接在固定x_out/y_out计算各波长；不是旋转图片，也不是几何光线追迹。
数值代价约 `O(Ny_out*Ny_in*Nx_in + Ny_out*Nx_in*Nx_out)`，必须先估内存和试算耗时。
不要构造 `(Ny_out,Nx_out,Ny_in,Nx_in)` 四维完整核，不默认8192²FFT及全图半径排序。

标量Fresnel传播要求近轴和相位屏等近似；不能只写λ远小于z就称其无条件适用。
报告孔径/输出角度尺度，必要时估计球面光程与二次项差异，调用现有 `sampling_diagnostics` 并保存结果。
该诊断只约束传播核，不自动证明高度跳变/材料相位已采样充分；02A只先预览，02B做真实DOE采样收敛。
若改用单次FFT，必须处理 `dx_out=lambda*z/(Mx*dx_in)` 的波长依赖，保留面积权重、相位和实际输出坐标，并验证映射；本批优先不引入这项额外复杂性。
